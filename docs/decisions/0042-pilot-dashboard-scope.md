# DR-0042: Pilot scope for the teacher dashboard

- **Status:** Accepted (Viraj, 2026-11-07)
- **Date:** 2026-11-07 · **Owner:** Viraj
- **Area:** Product
- **Source:** [teacher dashboard plan](../living/teacher-dashboard.md) (screens S1–S9)

## Context
The pilot starts in mid-January 2027 with 3–4 teachers. The dashboard has to be ready by about 2027-01-10 without delaying the student app.

## Decision
- **Live at pilot start:** This week, Topics, Students + student detail, Class join + roster, Assign, and "Useful / Not right?" feedback on insight cards.
- **Not in the pilot:** earnings ([DR-0040](0040-affiliate-for-all-teachers.md)); class sets, projector mode, "Show 3 questions", board explanations.
- **Sunday digest:** a manual WhatsApp send in the pilot (copy-paste from a generated text), with a weekly 2-question check-in, automated later, as with parent reports ([DR-0015](0015-parents-via-whatsapp.md)).
- **Paper builder:** planned separately; the prototype should be ready by pilot weeks 4–6 for the 500-channel pitch.

## Revisit triggers
- The P0 prototype feedback from teachers changes what matters
- Review date: 2027-01-15

## Consequences
+ A small, shippable dashboard alongside the student app
− The paper builder, the strongest pitch hook, isn't in the pilot dashboard itself
