# DR-0016: Stop or pivot only through a written decision; competitors matter only via revisit triggers

- **Status:** Accepted (Viraj, 2026-11-07)
- **Date:** 2026-11-02 · **Owner:** Viraj
- **Area:** Company / Process

## Context
Known founder pattern: abandoning ideas once the interesting build is done, when a competitor appears, or when a problem hits. Plus shyness and fear of failing.

## Options considered
1. Rely on motivation: the pattern repeats
2. **Structural rules: stop only by DR; competitors change plans only via revisit triggers; build gated behind customer milestones; a user scoreboard; a commitment device** ✅

## Decision
- Pausing, stopping or pivoting anything requires a decision record stating why and what we learned.
- A new competitor changes plans only if it fires a revisit trigger in an existing DR.
- Building gates: e.g. no scheduler v2 until 3 pilot teachers are confirmed.
- Commitment device: announce the pilot start date to the teachers and collect the 300 LKR before we feel "ready."
- See [founder playbook](../living/founder-playbook.md).

## Revisit triggers
- Monthly review shows the rules are being ignored → simplify them, don't drop them
- Review date: 2027-02-01

## Consequences
+ Drift becomes visible; stopping becomes learning
− A bit of process overhead
