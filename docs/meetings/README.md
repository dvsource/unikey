# Meetings

Raw notes from teacher calls, parent and student interviews, and advisor conversations.

- File name: `YYYY-MM-DD-<who>.md` (e.g. `2026-11-10-teacher-kamala.md`)
- Start from [`../templates/meeting.md`](../templates/meeting.md).
- Write facts about what people *do*, not compliments about the idea ([The Mom Test](../living/founder-playbook.md#reading-list)).
- When a note supports or contradicts an assumption, update [`../experiments/assumptions.md`](../experiments/assumptions.md).
