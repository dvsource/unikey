# T114 simulator rerun: grades and the repair at the session end (2026-11-24)

Engine change: DR-0052 grade effects (with DR-0056: the student's grade always counts), the repair queued for the end
of the session, skips always "later". Simulated students now grade themselves: honest (default), over-confident
(`confident-misconceptions`), under-confident (`underconfident-skipper`). Two new code checks: `no-retry-after-again`
and `repair-not-straight-after-miss`.

`npm run sim -- --days 28 --seed N --packs all` (v1) for seeds 1–3, and seed 1 on `--pack-set v2`: all 14 checks pass.

Check changes that came with T114 (each for a stated reason, not to make a run pass):
- `repair-steps-down` compares a piece with the latest miss on the piece's skill in this or the previous session (a
  carried repair); a piece with no such miss is a neighbour's and must be level 1. The old "nearest earlier miss in the
  session" no longer names the repaired miss once repairs wait for the end.
- `day-one-fit` counts a run of rights without Hards (no step-up credit, DR-0052) and without fast rights (never ladder
  credit, rule 1; the runner now logs `fast`). The fast-right gap was there before; new RNG draws exposed it on seed 2.

Found and fixed in the engine during the rerun: a deferred repair could serve the missed card itself (another variant),
since it had left the session's recent cards by then. Repairs now name their missed card and leave it out.

Judge packets build (`npm run judge -- packets --run runs/t114-s1`) and show each answer's pick and grade. The AI judge
pass itself was not launched: it needs Viraj's go-ahead (judge/JUDGING.md).
